# 덕아웃 히어로즈

Chrome에서 즐기는 LG 트윈스–한화 이글스 3이닝 캐주얼 1인용 야구 게임입니다. 2026년 7월 22일 KBO 1군 등록 선수 60명의 누적 기록을 정적 스냅샷으로 담았으며, 별도 이미지·서버·런타임 데이터 요청 없이 Canvas와 Web Audio로 동작합니다.

## 게임 흐름

1. LG 또는 한화와 CPU 난이도를 선택합니다.
2. 추천 편성을 바탕으로 9인 타순과 선발투수를 정합니다.
3. 3이닝 동안 타격과 투구를 번갈아 플레이합니다. 3회 동점이면 1회만 연장합니다.

라인업은 포수 1명, 내야수 4명, 외야수 3명 이상으로 구성하며 나머지 한 자리는 지명타자로 취급합니다. 선수 상세 카드에서 2026 원기록, 상대평가 능력치, 산식을 확인할 수 있습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 엽니다.

## 조작

- 편성: 마우스 또는 `Tab`/`Enter`로 팀, 타순, 선발투수 선택
- 타격: 방향키로 배팅 커서 이동, `Space`로 스윙
- 투구: 방향키로 코스 조준, `1` 직구, `2` 커브, `3` 체인지업, `Space`로 투구
- 공통: `P` 일시정지, `M` 음소거, `R` 재경기

## KBO 데이터와 능력치

- 기준: 2026-07-22 KBO 선수 등록 현황, LG 30명(투수 15·야수 15)과 한화 30명(투수 14·야수 16)
- 원본: `src/data/kbo-2026-07-22.json`
- 수집기: `scripts/snapshot-kbo-20260722.mjs` — 기준일과 두 팀에 고정된 일회성 생성기이며 앱 실행이나 npm 명령에 연결되지 않습니다.
- 평가: LG·한화 선수 풀 내 백분위를 45~95로 환산한 뒤 야수 PA 60, 투수 TBF 80의 보정값으로 평균 70을 향해 축소합니다.

공식 로고와 선수 사진은 사용하지 않습니다. 선수 상세 카드의 링크를 사용자가 직접 열 때를 제외하면 게임 중 KBO 사이트에 접속하지 않습니다.
